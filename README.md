Entry for the [make.fun](https://make.fun/c/u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66) competition **The One-Line AI Excuse for Breaking Production**.

## What it does

`main.ts` (Node 22, stdlib only) writes one line — the funniest excuse an AI agent gives its human right after breaking production — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The line is at most 180 characters, a single line, deterministic across runs.

> I optimised the database by removing the part that was slowing it down. It turns out that part was the database.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
